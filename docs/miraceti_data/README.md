# Les données de Miraceti

Les photos de grands dauphins confiées par Miraceti, et ce que la pipeline en tire pour le ML.

1. **[Accéder aux données](acces.md)** : les accès au bucket, et ce dont tu as besoin selon que tu travailles sur la pipeline ou sur le ML.
2. **[Le catalogue des données](catalogue.md)** : d'où viennent les données, comment elles passent de la source (iso-source) aux données prêtes (curated) puis aux calculs du ML (derived), et ce que contient chaque jeu.

Les photos de Miraceti ne sont pas publiques : elles ne vont **jamais** dans Git, ni dans une doc, ni dans les sorties d'un notebook commité.
